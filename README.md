Greenhouse Monitor v4.0 🌡️
Система мониторинга температуры для теплицы на ESP32 с датчиками DS18B20.

Возможности
Поддержка до 4 датчиков DS18B20

Двухрежимный WiFi (точка доступа + клиент)

Веб-интерфейс с графиками в реальном времени

Логирование в CSV с настраиваемым интервалом (3–3600 сек)

Буферизация данных для снижения износа Flash

Автоматическая ротация файлов при 512 КБ

Доступ по mDNS: http://greenhouse.local

Оборудование
ESP32

Датчики DS18B20 (1–4 шт.)

Резистор 4.7 кОм

Подключение к пину GPIO4

Установка
Установите библиотеки через PlatformIO или Arduino IDE:

OneWire

DallasTemperature

LittleFS

ESPmDNS

Замените адреса датчиков в функции initSensors() на свои

Настройте параметры WiFi в начале кода

Загрузите прошивку на ESP32

Веб-интерфейс
Эндпоинт	Описание
/	Главная страница
/data	JSON с данными
/download	Скачать CSV
/clear	Очистить историю
/storage	Информация о памяти
